# Curriculum and implementation status

All modules include lesson content and practice. Depth varies in this prototype; listed coverage is not a claim of live system integration.

| Module | Topic | Current practice |
| --- | --- | --- |
| 1 | Own the ticket from first contact to closure | Interactive intake and written ticket |
| 2 | Image a laptop with an approved deployment | Interactive BIOS and deployment simulation |
| 3 | Verify the laptop after imaging | Early guided workflow prototype |
| 4 | Install applications and drivers through Software Center | Early guided workflow prototype |
| 5 | Create and troubleshoot AD user accounts | Early account workflow; ADUC rebuild planned |
| 6 | Create AD groups and assign approved role access | Early guided workflow prototype |
| 7 | Understand domains, OUs, and device membership | Early guided workflow prototype |
| 8 | Find and retire device accounts in AD | Early guided workflow prototype |
| 9 | Diagnose network and DNS resolution | Interactive simulated DNS console |
| 10 | Resolve low disk space and clean up profiles | Early guided workflow prototype |
| 11 | Troubleshoot printers and print queues | Early guided workflow prototype |
| 12 | Support docks, monitors, peripherals, and LAN connections | Early guided workflow prototype |
| 13 | Troubleshoot sign-in and smart-card access | Early guided workflow prototype |
| 14 | Restore application, Citrix, and audio-device workflows | Early guided workflow prototype |
| 15 | Issue, replace, and recover equipment during offboarding | Early guided workflow prototype |

The independent capstone combines deployment, verification, access, and handoff decisions. It is a simulated assessment.
